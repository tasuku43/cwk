# Plan

Create a separately invoked smoke script that requires an explicit token, creates an isolated temporary configuration with only the three fixed read tasks, invokes a built production `cwk` binary, discards provider output and reports only the fixed task and success/failure. Never invoke a mutable operation. Build and dependency setup occur before the secret enters the environment. A scheduled default-branch workflow remains disabled unless an explicit repository variable is set; when enabled, missing token is failure, not a successful smoke result. Manual dispatch is excluded because it can select a modified workflow on another branch. GitHub schedule itself targets the default branch; the job must not depend on an event payload field that schedule does not guarantee. Pin GitHub actions consistently with existing workflows, use read-only permissions and persist no checkout credentials. Test the script using a fake binary that writes synthetic canaries to stdout/stderr and records invocation details outside stdout; test both success and failure, cleanup, and configuration permissions. Verify selection through existing CLI contracts. Document provisioning, output privacy, test-account access implications, and limited coverage. No real run occurs until independently provisioned credentials exist.
