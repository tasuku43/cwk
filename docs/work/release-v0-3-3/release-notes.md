# cwk v0.3.3

- Go を 1.26.10 に更新し、標準ライブラリの既知の脆弱性に対応しました。
- Homebrew Formula の冗長な version 指定を除き、公開済みアーカイブから版を判定できるようにしました。
- リリース入力の検査で、対象ファイルの列挙・読み込み・ハッシュに失敗した場合は失敗として扱います。

## v0.2.4 以前から更新する場合

- ヘルプの `--format agent` は廃止されています。`cwk <コマンド> --help` を使用してください。既存のエージェント設定にもこの形式がある場合は更新してください。
- 初回は `cwk config` で使用するコマンドを選択します。返信を含めたメッセージ確認には `cwk messages show --help` を参照してください。
- macOS 向けバイナリには Developer ID 署名および Apple notarization は付いていません。

この版は現在作業中のフィードバック全項目を含む最終版ではありません。
